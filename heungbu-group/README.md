# 흥부전 조각 맞추기 (조선 후기 생활과 문화 · 3학년 6반 공개수업)

다섯 모둠이 QR로 흥부전 한 마당씩을 맡아, 짧은 이야기 장면을 보고 PPT 내용 문제 5개를 풀면 글자(착·하·게·살·자)를 얻는다. 발표 화면에서 다섯 글자를 모아 '착하게 살자'를 완성한다.

- 주소: https://jajekedodu0422-web.github.io/-/heungbu-group/ (선생님 화면 = 첫 화면, 모둠 화면 = QR 주소)
- 1모둠 상속(착) · 2모둠 혼인·제사(하) · 3모둠 서민 문화 배경·한글 소설(게) · 4모둠 판소리(살) · 5모둠 풍속화·민화(자)
- 문제 형식: 사료 읽고 고르기, OX, 짝짓기, 모두 고르기, 낱말 도장 빈칸, 그림 속 찾기
- 틀리면 1번째는 "다시 생각해 보세요", 2번째부터 약한 힌트. 시간 제한 없음.
- 그림(img/)은 수업 PPT에 쓴 옛 그림(김홍도, 신윤복, 윤덕희, 「평양도」)을 잘라 쓴 것.
