# 흥부전 조각 맞추기 (조선 후기 생활과 문화 · 3학년 6반 공개수업)

다섯 모둠이 QR로 흥부전 한 마당씩을 맡아 되살리고, 받은 글자(착·하·게·살·자)를 모아 '착하게 살자'를 완성하는 모둠 활동.

- 주소: https://jajekedodu0422-web.github.io/-/heungbu-group/ (선생님 화면 = 첫 화면, 모둠 화면 = QR 주소)
- 1모둠 첫째 마당(상속·제사, 착) · 2모둠 둘째 마당(혼인, 하) · 3모둠 셋째 마당(서민 문화의 배경, 게) · 4모둠 넷째 마당(판소리·한글 소설, 살) · 5모둠 다섯째 마당(탈춤·풍속화·민화, 자)
- 모둠마다 ① 그림 찾기 ② 빈칸 채우기 ③ 거짓 문장 바로잡기를 풀면 글자를 얻는다.
